## 🚀 Перший запуск

При першому відкритті застосунку жодне ядро сервера ще не обрано. У верхній частині вікна є панель **"ЯДРО"**, де можна:

- 📦 обрати версію Paper та версію Java зі спадних списків (вони автоматично підвантажуються з інтернету);
- 📂 натиснути **"Папка"**, щоб вказати, куди зберегти файли сервера;
- ⬇️ натиснути **"Встановити"** — застосунок сам завантажить обрані версії Paper та Java, покладе їх у вказану папку та підготує сервер до запуску.

> 💡 Якщо у вас вже є готовий `server.jar` — просто скористайтесь кнопкою **"Обрати папку з ядром"** на панелі "СЕРВЕР" і вкажіть свій файл ядра.

---

## ⚙️ Панель встановлення ядра

- **ЯДРО** — випадний список доступних версій Paper. Останні версії показуються першими.
- **JAVA** — випадний список версій Java (Eclipse Temurin), сумісних з обраною версією Paper.
- **Папка** — куди буде встановлено файли сервера (ядро, конфіги, світи).
- **Встановити** — одна кнопка, яка завантажує і ядро, і потрібну Java, а після завершення одразу готує сервер до запуску.

Під кнопками з'являється короткий статус процесу встановлення — що саме зараз завантажується, і чи все пройшло успішно. ✅

---

## 📊 Показники навантаження

Одразу під панеллю ядра розташована смужка з живими показниками:

- 🧠 **CPU** — поточне навантаження на процесор
- 🐏 **RAM** — скільки оперативної пам'яті використовується
- ⏱️ **Час роботи серверу** — скільки часу сервер працює без перезапуску

Ці значення оновлюються автоматично, поки сервер запущено.

---

## 🎮 Керування сервером

Панель **"СЕРВЕР"** — це центр керування вашим локальним сервером:

- 🔴🟢 **Індикатор статусу** зверху панелі показує, чи сервер зараз увімкнено чи вимкнено
- ℹ️ **Версія / Java / Ядро** — коротка інформація про поточний обраний jar-файл сервера
- 🎚️ **Виділено RAM** — повзунок для вибору, скільки оперативної пам'яті виділити серверу (від 1 до 8 ГБ). Значення можна змінювати навіть до запуску сервера
- 🗂️ **Шлях до ядра сервера** — поле, куди можна вручну вписати шлях до `.jar`-файлу, або скористатись кнопкою нижче
- 📂 **Обрати папку з ядром** — відкриває системний провідник для вибору файлу ядра сервера

Три основні кнопки керування:

| Кнопка | Дія |
|---|---|
| ▶️ **Старт** | Запускає сервер |
| 🔁 **Рестарт** | Коректно зупиняє й одразу знову запускає той самий сервер (корисно після зміни конфігів) |
| ⏹️ **Стоп** | М'яко зупиняє сервер (аналог команди `stop` у консолі) |

## 📁 Файловий провідник

Панель **"ФАЙЛИ"** — це провідник по робочій папці сервера:

- 📂 Подвійний клік по папці — перехід усередину
- 📄 Клік по файлу — відкриває його в редакторі
- ⬅️ Кнопка **"Назад"** — повернення до батьківської папки
- ➕ Кнопка **"+"** — створення нового файлу або папки в поточному місці
- 🖱️ Правий клік по файлу чи папці відкриває контекстне меню з додатковими діями (перейменування, видалення тощо)
- 🔄 Кнопка **"Оновити файли"** — оновлює перелік файлів, якщо щось змінилося поза застосунком

Для кожного файлу показується його розмір, щоб було зручно орієнтуватись у великих папках (світи, бекапи). 📏

---

## 💻 Консоль

Панель **"КОНСОЛЬ"** відображає живий лог роботи сервера — усе, що сервер виводить під час старту, роботи та зупинки, включно з повідомленнями про вхід/вихід гравців, попередженнями та помилками (вони підсвічуються кольором для зручності). 🎨

Знизу є поле для вводу команд:

- ⌨️ Введіть команду і натисніть **Enter**, щоб надіслати її серверу
- ⇥ Клавіша **Tab** пропонує автодоповнення — доступні як вбудовані команди сервера, так і команди, додані встановленими плагінами
- ↕️ Стрілки **вгору/вниз** дозволяють гортати історію раніше введених команд

---

## 📝 Редактор конфігів

Панель **"РЕДАКТОР"** відкриває обраний у провіднику файл із підсвіткою синтаксису — зручно для правки `server.properties`, `config.yml`, `permissions.yml` та інших конфігів плагінів.

- 🗂️ Кілька файлів можна тримати відкритими одночасно — вони з'являються у вигляді вкладок зверху редактора
- 🟡 Жовта крапка на вкладці означає, що у файлі є незбережені зміни
- 💾 Кнопка **"Зберегти"** записує зміни на диск (працює також комбінація клавіш **⌘S**)
- ❌ Комбінація **⌘W** закриває поточну вкладку

---

## 🔤 Плейсхолдери та символи UTF-8

Дві додаткові кнопки над редактором полегшують роботу з текстовими конфігами:

- 🏷️ **Placeholders** — швидкий доступ до списку популярних плейсхолдерів PlaceholderAPI з можливістю переходу на повний перелік у документації
- ✨ **UTF-8** — палітра готових символів (рамки, стрілки, декоративні знаки), які часто використовують у повідомленнях і меню плагінів. Клік по символу копіює його в буфер обміну

## 🛠️ Збірка з вихідного коду вручну

Якщо ви хочете внести правки в код і зібрати застосунок самостійно (замість використання готового `.dmg`), знадобиться macOS з встановленими:

- 🐍 **Python 3** — перевірити наявність: `python3 --version` у Терміналі; якщо не встановлено — можна поставити через [python.org](https://www.python.org/downloads/) або Homebrew: `brew install python3`
- 🍎 **Xcode Command Line Tools** — потрібні для утиліт `hdiutil` та `iconutil`, які вже входять у стандартну поставку macOS (`xcode-select --install`, якщо ще не встановлені)

### 📦 Кроки збірки

1️⃣ Розпакуйте або склонуйте вихідний код в одну папку

2️⃣ Відкрийте Термінал у цій папці

3️⃣ Дайте скрипту збірки права на виконання:

```bash
chmod +x build.sh
```

4️⃣ Запустіть збірку:

```bash
./build.sh
```

Скрипт автоматично:

- 🐍 створить ізольоване Python-середовище (`.venv`) і встановить усі потрібні залежності з `requirements.txt`
- 🖼️ за наявності файлу `icon.png` — сконвертує його у формат `.icns` для іконки застосунку
- 📦 зібере готовий `.app`-застосунок через PyInstaller
- 💿 запакує його у `.dmg`-образ, готовий для встановлення чи розповсюдження

Після завершення збірки готові файли з'являться в папці `dist/`:

```
dist/
├── MC Server Manager.app     ← сам застосунок
└── MC-Server-Manager.dmg     ← образ для встановлення
```

**Системні налаштування → Конфіденційність і безпека → "Все одно відкрити"**
