Ядро — кнопкою «Обрати ядро...» вкажіть server.jar. Папка з ним стане робочою для сервера.

Старт / Рестарт / Стоп — запускає сервер, коректно перезапускає його (стоп і повторний старт того ж ядра) або зупиняє (командою stop).

Консоль — тут з'являється лог сервера; знизу можна ввести команду і натиснути Enter.

Файли — провідник по папці сервера. Подвійний клік по папці — перехід всередину, клік по файлу — відкриває його в редакторі.

Редактор — правки конфігів із підсвіткою синтаксису, кілька файлів відкриваються у вкладках зверху. Жовта крапка на вкладці — незбережені зміни. Кнопка «Зберегти файл» записує зміни на диск.
